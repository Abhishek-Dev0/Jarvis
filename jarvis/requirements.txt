# torch: install a CUDA build, not the plain "torch" CPU wheel, if this
# machine has an NVIDIA GPU -- e.g. (Python 3.14, the version this project
# targets, only has CUDA wheels up to the cu128 index as of this writing):
#   pip install torch --index-url https://download.pytorch.org/whl/cu128
# A CPU-only torch here silently disables CUDA everywhere that checks
# torch.cuda.is_available() (faster-whisper's device pick, hardware.py's
# reasoning-model VRAM-budget sizing) -- real bug found in the packaged
# app: a CPU-only torch got bundled by mistake, which made
# recommend_reasoning_model() fall back to a RAM-based budget instead of
# VRAM and pick an oversized model tag. `pip install -r` alone gets the
# plain torch>=2.0 CPU wheel; run the CUDA install above first if you have
# an NVIDIA GPU, then `pip install -r requirements.txt` for everything else.
torch>=2.0
numpy
regex
requests
beautifulsoup4
psutil
pyserial
mcp
yfinance

scikit-image

# voice I/O + translation (modules/voice.py, modules/translate.py) — optional at
# import time (each module degrades gracefully if missing) but required for --voice
faster-whisper

speechbrain

# faster-whisper's backend (ctranslate2) needs CUDA 12's cublas/cudnn even

# without these, whisper on cuda loads fine but crashes on the first real
# transcribe() call. See modules/voice.py's _register_cuda_dll_dirs().
nvidia-cublas-cu12
nvidia-cudnn-cu12
